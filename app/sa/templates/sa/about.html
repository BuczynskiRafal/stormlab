Stormwater Analysis System

An integrated platform for hydraulic modeling and machine learning-based classification of storm sewer networks.

  • SWMM 5.2
  • PN-EN 752:2008
  • 12 catchment types
  • C3c GraphSAGE (66 features)

Overview

This system processes SWMM (Storm Water Management Model) files through a pipeline that validates hydraulic parameters, classifies catchments (via explicit SWMM [TAGS] or a 12-class neural classifier fallback), and generates conduit-level engineering recommendations using a 2-hop upstream GraphSAGE network (C3c) trained on 66 physical features (v4_physical).

The methodology integrates Polish and European hydraulic design standards with graph-based deep learning and multi-source soft-label supervision (primary_action_v3) to evaluate both local conduit capacity and upstream network context.

2. Subcatchment Classification

When subcatchment categories are not explicitly supplied in the SWMM [TAGS] section, the system falls back to a feed-forward neural network trained on 12 hydrological features (`full_12` contract) across 12 land-use and terrain classes.

Classifier Architecture

12 neurons (hydrological and runoff features)
Hidden layers
32 / 16 neurons, ReLU activation with dropout
Output layer
12 neurons, softmax (alphabetical class order)

3. Graph Neural Network Recommendation System (C3c)

The primary serving model (gnn_c3c_winner_v1.weights.h5) is a 2-hop upstream GraphSAGE architecture (gnn_up_k2__f2_l2) operating on the 66-column physical feature contract (v4_physical) with training-fold mean imputation (c3c_imputation_plan.json), trained on 5,056 synthetic DYNWAVE networks under soft multi-source supervision (primary_action_v3). A 33-feature tabular MLP (recomendations.keras) is retained as a fallback when GNN_ENABLED=false.

Model Architecture & Evaluation

Catchment Classifier (Plan 19 / K1)

  • Test accuracy (K1) 85.7% (Bayes ceiling 86.7%)
  • Rakowiec holdout (v3 tags) 34 / 37 (91.9%)
  • Feature set full_12 (INP + SWMM RPT)
  • Classes 12 land-use / terrain types

Recommendation Model (C3c GraphSAGE)

  • Architecture 2-hop upstream GraphSAGE
  • Feature contract v4_physical (66 features)
  • Training pool (C3c) 5,056 DYNWAVE networks
  • Wrocław strict holdout 54 / 62 admissible (87.1%)

Serving Models & Baselines
